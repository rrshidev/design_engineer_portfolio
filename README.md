Подбор комплектующих (плиты, знаки, толкатели, литьевые втулки и т.д по импортным и отечественным каталогам). Проектирование (3д-моделирование сборки пресс-формы, конструкторская документация по ЕСКД).

## 🛠️ Навыки и стек технологий
* **CAD/САПР:** SolidWorks (Advanced), Компас-3D, AutoCAD.
* **CAE/Расчеты:** SolidWorks Simulation (Линейный статический анализ, тепловые расчеты). Mold Flow (Анализ проливаемости деталей из композитов). Flow Simulation (Анализ поведения взвешенных частиц в воздушных потоках разной конфигурации).
* **ЕСКД / ISO:** Глубокие знания стандартов оформления чертежей, допусков и посадок (согласно ЕСКД). Применение стандартных подходов при проектировании и выборе стандартных изделий по ГОСТ\ISO.
* **DFM (Design for Manufacturing):** Проектирование под гибочное производство, ЧПУ-фрезеровку, литье пластмасс, 3D-печать, плазменную и лазерную резку металла, слесарно-сварочные работы, нестандартные операции и специальное назначение.
